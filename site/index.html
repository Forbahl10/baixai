Cole um link. Escolha o formato. Baixe.

Uma extensão do Chrome conectada a um aplicativo que roda no seu computador: nenhum servidor processa seus downloads, não há conta e não há telemetria.

Como instalarO que funciona

Versão {{VERSION}} — pré-lançamento. A extensão ainda não está publicada na Chrome Web Store; por enquanto ela é instalada manualmente (passos abaixo).

Como funciona

1. Extensão

A interface no Chrome: campo de link, prévia, formatos e a lista de downloads.

2. Aplicativo auxiliar

Roda no seu computador com yt-dlp, gallery-dl e FFmpeg. Uma extensão sozinha não executa Python nem FFmpeg, por isso este app é instalado à parte.

3. Conexão segura

O Chrome fala com o app por Native Messaging: sem portas abertas e só para esta extensão.

Instalação

Passo 1 — Extensão (modo desenvolvedor)

Baixar a extensão (.zip)

  1. Extraia o ZIP em uma pasta que você vai manter.
  2. Abra chrome://extensions, ative o Modo do desenvolvedor e clique em Carregar sem compactação, escolhendo a pasta extraída.
  3. Copie o ID da extensão mostrado no cartão (ou na aba Ajuda do Baixaí).

Passo 2 — Aplicativo auxiliar

SistemaDownloadSituação

No macOS, no Terminal:

tar -xzf baixai-helper-{{VERSION}}-macos-arm64.tar.gz
cd baixai-helper-{{VERSION}}-macos-arm64
./install.sh --extension-id SEU_ID_AQUI

O instalador copia o app para a sua pasta de usuário (sem sudo), registra o host do Chrome e, se você aceitar, baixa o FFmpeg conferindo o SHA-256. Para remover: ./uninstall.sh.

Passo 3 — Verificar

Reinicie o Chrome e abra o Baixaí. Deve aparecer “Aplicativo local conectado”. Se não, abra a aba Diagnóstico.
